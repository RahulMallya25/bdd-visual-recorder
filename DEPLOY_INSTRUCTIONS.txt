📋 WHAT YOU NEED TO DO:

STEP 1: Deploy Backend to Railway (5 minutes)
┌────────────────────────────────────────────────────────────┐
│ 1. Go to: https://railway.app                              │
│ 2. Sign in with GitHub                                     │
│ 3. New Project → Deploy from GitHub                        │
│ 4. Select: RahulMallya25/bdd-visual-recorder               │
│ 5. Settings:                                               │
│    - Root Directory: backend                               │
│    - Start Command: node server.js                         │
│ 6. Generate Domain → COPY THE URL                          │
└────────────────────────────────────────────────────────────┘

STEP 2: Configure Vercel (2 minutes)
┌────────────────────────────────────────────────────────────┐
│ 1. Go to: https://vercel.com/rahulmallya25s-projects/      │
│           bdd_visual_recorder                              │
│ 2. Settings → Environment Variables                        │
│ 3. Add New:                                                │
│    - Name: VITE_BACKEND_URL                                │
│    - Value: [Paste Railway URL from Step 1]               │
│    - Environment: Check all boxes                          │
│ 4. Save                                                    │
└────────────────────────────────────────────────────────────┘

STEP 3: Redeploy Frontend (2 minutes)
┌────────────────────────────────────────────────────────────┐
│ Run in terminal:                                           │
│                                                            │
│   vercel --prod                                            │
│                                                            │
│ OR from Vercel dashboard:                                  │
│   Deployments → Latest → ... → Redeploy                    │
└────────────────────────────────────────────────────────────┘

STEP 4: Connect Backend to Frontend (1 minute)
┌────────────────────────────────────────────────────────────┐
│ 1. Go back to Railway dashboard                            │
│ 2. Click backend service → Variables                       │
│ 3. Add New:                                                │
│    - Name: FRONTEND_URL                                    │
│    - Value: https://bdd-visual-recorder.vercel.app         │
│ 4. Save (auto-redeploys)                                   │
└────────────────────────────────────────────────────────────┘
